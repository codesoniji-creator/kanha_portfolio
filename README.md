# Kanha Soni — Portfolio

A simple personal portfolio built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Build for deployment

```bash
npm run build
```

The production files are generated in `dist/`.

## Before deployment

1. Add your GitHub URL in `src/main.jsx`.
2. Add project GitHub/demo links if available.
3. Add a profile photo if you want one.
4. Replace any project placeholder descriptions with your final details.
